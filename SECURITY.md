# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in SwissSuite AI, please report it privately rather than opening a public GitHub issue.

- **Email:** info@swisswpsecure.com
- **Website:** https://www.swisswpsecure.com

Please include:

- The plugin version affected (see `readme.txt`'s `Stable tag`, or the version shown in WordPress Admin → Plugins).
- Steps to reproduce, or a proof-of-concept.
- The potential impact as you understand it.

We will acknowledge your report and work with you on a fix and, where appropriate, coordinated disclosure. Please give us reasonable time to address the issue before any public disclosure.

## Supported Versions

Only the latest version published on the WordPress.org Plugin Directory is supported with security fixes. Please update to the latest version before reporting an issue, to confirm it still reproduces.

## Scope

This policy covers the SwissSuite AI plugin as published on WordPress.org and its published source in this repository. It does not cover third-party plugins, themes, or hosting environments.
