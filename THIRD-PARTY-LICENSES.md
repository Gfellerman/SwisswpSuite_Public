## react / react-dom

**Not bundled.** `react` and `react-dom` are listed as build-time dependencies (`plugin-src/package.json`), but the production bundle does not ship their code. `vite.config.ts` aliases the `react`, `react-dom`, `react-dom/client`, `react/jsx-runtime`, and `react/jsx-dev-runtime` import specifiers to small local shim modules (`src/vendor-shims/*.ts`) that, at runtime, read the copy of React that WordPress core itself registers and loads under the `react` / `react-dom` script handles. This avoids shipping a second copy of React alongside the one WordPress already loads. See `plugin-src/BUILDING.md` for the full explanation.
